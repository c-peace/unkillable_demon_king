## Active decisions

- Treat request `messages` as authoritative and keep transport stateless.
- Preserve raw history; derived clinical state supplements but never silently overrides it.
- Keep risk, evidence need, and clarification mode as independent planning decisions.
- Retrieve only for named source-sensitive claims and stop when critical requirements close or the
  cumulative request budget is exhausted.
- Use only registry-backed `cite_uid` evidence and never infer answer confidence from retrieval
  relevance alone.
- Run semantic verification and L2 review conditionally; all advanced layers remain ablatable.
- Do not reconstruct hidden HealthBench cases, rubrics, or answer keys.

## Active blockers

- A historical CoEval run was cancelled after independent candidate failures (L2 timeout/HTTP 502)
  and judge-format failures; its aggregate score is not comparable.
- CoEval permits 16 concurrent candidate requests with a 180-second timeout. The published harness
  has no upstream L2 concurrency gate, uses a 60-second per-call timeout, and disables the whole-
  request deadline.
- Optional retrieval verification and review can add L2 work while the upstream is already
  degraded.
- Complete schema/error/pagination coverage across all 21 MCP tools is not live-verified.
- Organizer evaluator resource limits and the expanded advanced tool-calling documentation remain
  unknown.

## Next actions

1. Add an upstream L2 concurrency governor, deadline-aware admission, and reserved final-answer
   budget below the evaluator timeout.
2. Preserve an L2-generated provisional answer and skip optional verifier/reviewer work when the
   upstream or remaining deadline is degraded.
3. Add stage-specific token/time budgets, status-aware retry with jitter, and privacy-safe queue and
   timeout metrics; stress-test at candidate concurrency 16.
4. Run bounded live L2/MCP probes, policy ablations, and then a fresh CoEval trial.
5. Treat judge parser repair and scoring-failed replay as a separate CoEval concern.
